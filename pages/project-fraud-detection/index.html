NEOPOLIS 📅 Feb - Jun 2024 🎯 End-of-Studies Project

Insurance Fraud Detection AI System

Developed an AI-powered system to detect and analyze fraudulent insurance contracts, featuring machine learning models, ETL pipelines, interactive dashboards, and a full-stack web application.

Python Machine Learning Power BI Talend ETL Flask ReactJS

🎯 The Challenge

NEOPOLIS, a leading insurance technology company, faced significant financial losses due to fraudulent insurance claims. Manual detection methods were time-consuming, inconsistent, and failed to identify sophisticated fraud patterns. They needed an intelligent system capable of:

  • Analyzing large volumes of insurance contract data in real-time
  • Identifying complex fraud patterns that human reviewers might miss
  • Providing actionable insights through interactive dashboards
  • Integrating seamlessly with their existing workflow

💡 The Solution

I designed and implemented a comprehensive fraud detection ecosystem that combines machine learning, data engineering, and modern web technologies:

  • ML Models: Built classification models using Random Forest, XGBoost, and ensemble methods to predict fraud probability with high accuracy
  • ETL Pipeline: Created robust data pipelines with Talend to extract, clean, transform, and load data from multiple sources
  • Power BI Dashboards: Designed interactive dashboards with DAX measures for real-time fraud monitoring and trend analysis
  • Web Application: Developed a Flask backend API with ReactJS frontend for case management and fraud investigation
  • Alert System: Implemented automated alerts for high-risk contracts requiring immediate review

⚙️ Key Features

  • Real-time Scoring: Instant fraud risk assessment for new insurance applications
  • Pattern Recognition: ML algorithms identify hidden fraud networks and repeat offenders
  • Interactive Dashboards: Drill-down analytics with geographic, temporal, and category filters
  • Case Management: Web interface for investigators to review, annotate, and track fraud cases
  • Audit Trail: Complete logging of all predictions and decisions for compliance
  • Model Retraining: Automated pipeline to update models with new fraud patterns
